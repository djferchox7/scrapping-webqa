# scrapping-webqa
Script para scrapping con selenium y phyton

## freshdesk_print_tickets.py
Dada la limitacion de la plataforma Freshdesk de mantener las cuentas sprout por 6 meses fue requerido descargar todos los tickets con los comentarios, respuesta y notas internas completas.
El script se conecta al dashboard y usa una url para imprimir el ticket con todos los datos.
